# evi-assistant.github.io

The landing site for **eVi** — a local-first personal AI assistant — served at
**https://evi-assistant.github.io/**.

This repo holds only the static landing page (`index.html` + `styles.css`). The
project itself lives at **https://github.com/evi-assistant/evi-ai**.

- Package: `pip install evi-assistant`
- Skills catalog: https://github.com/evi-assistant/evi-skills
- Desktop downloads: https://github.com/evi-assistant/evi-ai/releases/latest

Edit `index.html` / `styles.css` and push to `main`; GitHub Pages redeploys
automatically (Settings → Pages → Deploy from branch `main` / root).
